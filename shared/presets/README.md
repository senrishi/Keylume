# RS

`RS.json` is a complete 61-key static layout. Cyan keys form R on the left and pink keys form S on the right, using only the top four physical rows. All bottom-row keys and the background are off. The strokes follow key positions rather than the legends printed on them.

The compact four-row glyphs use these strokes (the physical keys are staggered):

```text
R       S
###.    .###
#..#    ##..
###.    ..##
#..#    ###.
```

This layout is saved as `RS` in the macOS app's user presets. Select **Presets → RS**, then **Apply to Keyboard** to recall it. The JSON file preserves the exact colors in Git.
