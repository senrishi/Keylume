GOOD TO KNOW

Connect. Create. Keep.

Use desktop Chrome or Edge over HTTPS (or localhost). Connect the keyboard to the computer running this browser, close other RGB apps, then select the vendor RGB interface when prompted. Safari, Firefox, and mobile browsers may let you design layouts but do not support keyboard control here.

If the device is absent or its output reports are unavailable, the browser may protect this keyboard’s HID reports. This app cannot override browser restrictions. Use the native macOS app if the browser will not expose the interface. On Linux, local hidraw permissions may also be required.

Static layouts and firmware animations are sent only when you press Apply. Firmware animation previews are symbolic; the keyboard renders the actual motion. RGB power consumption is not measured.

For your homelab, serve the contents of web/dist at an HTTPS origin. No backend or account is required for self-hosting. Browser presets are local to each origin and machine; use JSON export/import to transfer them. You must grant keyboard access separately on each machine.
