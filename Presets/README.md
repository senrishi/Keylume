# RS

`RS.json` is a complete 61-key static layout. Cyan keys form R on the left and pink keys form S on the right, using all five physical rows. The keyboard's stagger and wide modifiers make the strokes approximate. All other keys are off.

This layout is saved as `RS` in the macOS app's user presets. Select **Presets → RS**, then **Apply to Keyboard** to recall it. The JSON file preserves the exact colors in Git.
