# Project workflow

Track changes in this repository and commit and push completed changes to origin, as requested by the owner. Native macOS source is in apps/macos; build with `zsh scripts/build-macos.sh` and run bundled validation before installing. Keep only the installed application at `/Applications/Keylume.app`; remove the dist app after installation and do not commit build artifacts. Replace the legacy MK1300-RGB.app during migration, preserving its `local.mk1300.rgb` bundle identifier, saved presets, and preferences.

Windows source is in apps/windows; run its tests and build using npm scripts. Browser/shared editor source is in apps/web; run `npm test` and `npm run build` there. Existing Sites identity is apps/web/.openai/hosting.json; preserve it and the public audience. Keep desktop package versions aligned with VERSION. Tag releases only after checks pass and monitor GitHub Actions through release publication. Never claim Windows hardware validation from simulated-device tests or packaging alone.
